Seams — #1, #2, #3 fixed this pass (working→in-flight · landed auto-clears · MIA its own lane); go-around removed. #5–#8 remain.
1
Approach hides active work precedence
A busy session with a merged PR (same branch, before go-around) shows in Approach, not In-flight — looks done while it's running.
2
Landed is sticky precedence
Land a session then keep working in it → it stays in the Landed row (dimmed) even while busy, until you hit ×.
3
"idle" means two opposite things overloaded
Registry idle → Holding (your move). Transcript-inferred idle → In-flight/MIA (mid-work, quiet). Same word, opposite lanes.
4
Three states collapse into Cold ambiguous
dormant / suspected-done / unknown all → Cold. A broken parse (unknown) hides among overnight-cold; archived desktop sessions vanish into the collapsed footer.
5
Registry authority misses desktop sessions coverage
Desktop-run sessions (incl. the one you talk to me in) never get busy/idle — always the fuzzy transcript inference.
6
Non-PR work has no "done" signal coverage
Approach is merged-PR-only. Work on main, or a session with no PR, can never reach Approach — it just fades to Cold.
7
Holding pings on every turn-end noise
Registry idle → needs-input immediately + notify delay 0 → every live session finishing a turn flashes Holding and pings.
8
Dead error state + inconsistent grace cruft
error is in the type/UI but never produced. The 8s grace only applies to the transcript path — registry idle snaps to Holding instantly.
